# neco-linear-dense

[English](README.md)

`neco-linear-dense` は、数値線形代数に使う密行列を提供します。行列は、形状と一致する個数の要素を列優先の順で保持します。

構築時には、行数×列数が `usize` に収まること、要素の個数がその積と一致すること、要素の個数が `isize::MAX` 以下であることを検査し、メモリ確保の成否を確かめます。

`f64` の行列とベクトルの積では、入力ベクトルの長さも検査の対象です。

## 公開 API

- `DenseMatrix<T>`: 形状と要素を private なフィールドで保持する密行列
- `from_column_major`: 列優先の要素から行列を構築する
- `from_row_major`: 行優先の要素を列優先の格納順へ変換して構築する
- `try_zeros`: すべての要素を一つの値で初期化して構築する
- `value`: 検証済みの行と列の添字で要素を参照する
- `LinearOperator<f64>`: 行列とベクトルの積を計算する

## ランタイム構成

既定では標準ライブラリを使います。既定機能を無効にすると、動的メモリ確保だけを前提とする `core + alloc` の構成になります。
