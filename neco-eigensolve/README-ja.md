# neco-eigensolve

[English](README.md)

`neco-eigensolve` は、実対称一般化固有値問題を決定的な手順で解く数値ソルバーで、標準ライブラリを使わない `core + alloc` の構成でも利用できます。

## 公開 API

- `EigensolveConfig`: 要求するモード数、許容差、反復上限
- `EigensolveError`: 入力・設定・結果の検証とメモリ確保の失敗
- `EigensolveRequest<R>`: 問題、設定、射影参照
- `EigensolveResult<R>`: 固有空間、収束状態、スペクトルシフト、要求から移した射影参照
- `solve_symmetric_f64`: 密な実対称問題を解く
- `solve_request_symmetric_f64`: 要求を消費して解き、射影参照を計算結果へ移す
- `projection_reference`: 要求または結果が持つ射影参照を借用する
- `into_projection_reference`: 結果が所有する射影参照を取り出す
- `solve_csr_symmetric_f64`: CSR 形式の実対称問題を解く

要求と結果が持つ射影参照は、呼び出し側が型 `R` で渡す任意の値です。ソルバーは、この値をそのまま要求から結果へ移します。

射影参照の用途は、厳密値を f64 へ射影した行列の来歴を、計算結果に添えることです。代表的な型は、剛性行列と質量行列の来歴を持つ `CertifiedGeneralizedEigenInput` で、`neco-linear-exact` が提供します。

## 計算エンジン

Jacobi 法の計算部は、質量行列として厳密な単位行列だけを受け付けます。行と列の順で最大の非対角要素を選び、決定的な回転を適用します。返す固有空間では、各基底ベクトルを 2 ノルム 1 に正規化し、絶対値が最大の成分のうち最初のものが正になるように符号をそろえます。

固有空間と収束の規則は、どの基底ベクトルが一つの固有空間をなすか、返すモードの数、収束の判定、スペクトルシフトの値を定めます。

- 算出した固有値が厳密に等しい基底ベクトルだけが、一つの固有空間をなす。許容差は、残差による収束の判定にだけ使う
- 要求したモード数が固有空間の途中で尽きる場合も、固有空間を分割せずに完全な形で返す。そのため、返す数が要求した数を超える場合がある
- 絶対残差または相対残差が、対応する許容差を満たすモードを収束と判定する
- 結果のスペクトルシフトは常に `Complex<f64>::zero()` である

## 依存

- `neco-generalized-eigen`: 一般化固有値問題と結果の型
- `neco-linear-dense`: 密な問題行列
- `neco-sparse`: CSR 形式の問題行列
- `neco-complex`: 複素数のスペクトルシフト

## ランタイム構成

既定では標準ライブラリを使います。既定機能を無効にすると、動的メモリ確保だけを前提とする `core + alloc` の構成になります。
