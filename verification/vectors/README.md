# 代数演算における検証ベクター

このディレクトリの検証ベクターを観測器の `--vectors` に渡すと、検査器が記録どおりの観測を受理し、改変した観測と規約に反する入力を拒否するかを確かめることができます。
`--vectors` には、三つのディレクトリのいずれかを渡します。

- `known/`: 初版の演算族の成功と失敗の観測を記録した、正規形の JSON 文書
  - 判定: 13 件の観測がすべて `verified` になる
- `tampered/`: 観測値、演算族、ダイジェスト、正規形のバイト列に対する改変
  - 判定: 各観測が `refuted` か `invalid` になる
- `invalid/`: 正規形の JSON の規約に反する入力と、UTF-8 として復号できないバイト列を小文字の 16 進数で表した `non-utf8.hex`
  - 判定: すべての入力が `invalid` になる

`tampered/` のうち、正規形のバイト列の改変を収めた `canonical-bytes.json` では、項目の順序を正規形から外しています。

`requests/` の二つのファイルは、生成器へ渡す生成要求と、その要求から生成した観測バッチで、どちらも生成器の `self-check` に渡せる入力です。

## ベクターの形式

`known/` と `tampered/` にある JSON の検証ベクターは、二つの項目を持つ文書です。

- 形式識別子: `schema`
- 観測の一覧: `cases`

各観測は、四つの項目だけを持ちます。

- 観測識別子: `caseId`
- 演算族: `operation`
- 入力: `input`
- 観測値: `observation`
