# 代数演算における検証成果物の配置

観測器の `--vectors` と `--smoke` の実行では、このディレクトリに配置した検査器と観測バッチを使います。

- `--vectors`: 配置した検査器で検証ベクターを検査する
- `--smoke`: 配置した観測バッチ ( 生成器の出力 ) を読み、配置した検査器で検査する

Lean と Rust のそれぞれの構築とテストを終えてから、検査器の実行ファイルと観測バッチを、このディレクトリの下に配置します。

- `lean/neco-algebra-checker`: 独立検査 ( `protocol/README.md` を参照 ) を行う検査器の実行ファイル
- `rust/algebra-observation-batch.json`: 生成器が公開 API を呼んで書き出した観測バッチ

観測器は、どちらの実行方法でも、まずこの二つが配置されていることを確かめます。そのうえで、照合結果の要約を `digests/<sha256>.json` としてこのディレクトリへ書き出します。これらの成果物は実行ごとに生成し、Git には含めません。
